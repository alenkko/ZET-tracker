# ZET-tracker 

Real-time tracking of ZET vehicles on iPhone and Apple Watch.

## Features

- Real-time vehicle positions
- Map view with live updates
- Apple Watch companion app
- WatchConnectivity sync

## Tech Stack

- Swift
- SwiftUI
- MapKit
- WatchConnectivity
- GTFS Realtime
